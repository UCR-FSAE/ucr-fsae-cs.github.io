How we build

From a signal to a system.

Software for a race car has to work with real sensors, wiring, control units, and the people integrating them.

01 /

Understand the hardware

Start with the vehicle system, its electronics, the signals it exchanges, and the conditions it needs to handle.

02 /

Build and review

Develop firmware and tools in shared repositories so teammates can review changes, follow the work, and build on it.

03 /

Test with the system

Bring software together with vehicle hardware, inspect the data, and refine the integration as the car evolves.

04 /

Share what we learn

Public repositories make project history and engineering work easier for future teammates, collaborators, and supporters to explore.
